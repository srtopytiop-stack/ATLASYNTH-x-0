# Security Policy

ATLASYNTH is an analysis and research project. It does not support live exchange-order execution.

- Do not report secrets in public issues.
- Never commit `.env`, Telegram tokens, exchange credentials, or personal account data.
- This project must remain public-market-data-only unless a separate, independently reviewed specification changes the trust boundary. Live trading is out of scope for the current project.
- For a security issue, contact the repository maintainer privately through an available GitHub security contact or private channel. Include affected version, reproduction steps, impact, and a safe mitigation suggestion.
